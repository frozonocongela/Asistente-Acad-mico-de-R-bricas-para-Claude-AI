# Asistente-Acad-mico-de-R-bricas-para-Claude-AI
Este proyecto contiene una **skill** personalizada para Claude AI diseñada para actuar como un tutor y evaluador académico. Su función principal es analizar los requisitos de una tarea, proyecto o rúbrica de evaluación y compararlos con el trabajo del estudiante para garantizar que se cumplan todos los puntos requeridos antes de la entrega.
