# Asistente Académico de Rúbricas para Claude AI

## Descripción
Este proyecto contiene una **skill** (conjunto de instrucciones estructuradas) diseñada para transformar a Claude AI en un tutor y evaluador académico personal. Su función principal es analizar los requisitos de una tarea o proyecto frente a su rúbrica de evaluación, verificando el cumplimiento de cada criterio antes de la entrega final.

## Objetivo
Facilitar la revisión automática y estructurada de trabajos escolares, ayudando a los estudiantes a identificar requisitos faltantes, corregir errores de formato o contenido y asegurar el cumplimiento total de los criterios de evaluación establecidos.

## Modo de Uso

1. Copiar el contenido del archivo [`SKILL.md`](./SKILL.md) ubicado en este repositorio.
2. Ingresar a Claude AI y pegar el prompt para activar el comportamiento del evaluador.
3. Proporcionar el texto de la rúbrica del proyecto junto con el borrador o trabajo a revisar.
